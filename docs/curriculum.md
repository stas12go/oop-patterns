# Учебный план

Паттерны изучаются в три стадии: сначала принципы, которые паттерны кодируют,
затем паттерны от простых к сложным, в конце — продвинутые и спорные.

## Как проходит обучение

Формат: **я даю задачу и тесты, ты пишешь код, я проверяю и разбираю**.

Один пункт плана = один заход:

1. Я выдаю ТЗ: ситуация, требования к API, список граничных случаев, ссылка на папку.
2. Я заранее кладу в репозиторий падающие тесты (`patterns/<Категория>/<Паттерн>/tests/`).
3. Ты реализуешь `patterns/<Категория>/<Паттерн>/src/` так, чтобы `composer test` был зелёным.
4. Если застрял — пишешь «подсказку» и получаешь подсказку следующего уровня
   (1. суть задачи словами → 2. структура классов и их имена → 3. сигнатуры → 4. готовый код).
5. После зелёных тестов я задаю 2–3 вопроса по коду. Цель — не «угадал», а можешь объяснить,
   почему такое решение, и где оно сломается.
6. Я пишу `README.md` паттерна (проблема, решение, диаграмма, анти-паттерны, аналоги в Symfony/Laravel).
7. Отмечаем прогресс здесь и коммитим.

Тесты, которые я даю, — это контракт, а не эталонное решение: если API неудобен,
меняем ТЗ и тесты вместе, но не подгоняем решение под «правильность с моей стороны».

## Статусы

`⬜` не начато · `🔄` в процессе · `✅` сдано и разобрано · `⏸️` отложено

## Шаблон папки паттерна

```
patterns/<Категория>/<Паттерн>/
  README.md    разбор: проблема, решение, диаграмма, анти-паттерны, аналоги в фреймворках
  src/         реализация (PSR-4: OopPatterns\<Категория>\<Паттерн>\)
  tests/       тесты (PSR-4: OopPatterns\Tests\<Категория>\<Паттерн>\)
  Example.php  запускаемый сценарий: php patterns/<Категория>/<Паттерн>/Example.php
```

Требования к коду, который сдаётся:

- PHP 8.2+, строгие типы `declare(strict_types=1)`, `final` где уместно, без `mixed` без причины.
- Каждая публичная сущность — с docblock: назначение и инвариант.
- Тесты: happy path + минимум два граничных случая из ТЗ.
- Нет глобального состояния, `sleep`, зависимостей от сети и файловой системы.

## Команды

```bash
composer install          # зависимости
composer test             # все тесты
vendor/bin/phpunit --testsuite=unit
vendor/bin/phpunit patterns/Behavioral/Strategy   # один паттерн
php patterns/Behavioral/Strategy/Example.php      # запустить пример
```
